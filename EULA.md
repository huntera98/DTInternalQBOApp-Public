## 3. Intended Use

This Application is designed to facilitate accounting data migration into QuickBooks Online via the Intuit QuickBooks Online API. It is used exclusively by authorized personnel of Atkins CPA LLC to import general ledger data, journal entries, and related financial records into client QuickBooks Online company files.

## 4. QuickBooks Online Integration

This Application connects to QuickBooks Online using OAuth 2.0 authentication in accordance with Intuit's developer policies. By authorizing this Application, you grant it permission to:

- Read account, department, and entity data from the connected QuickBooks Online company
- Create journal entries and related transactions in the connected QuickBooks Online company
- Query financial data necessary for data validation and reconciliation

## 5. Data Handling

- All data processed by this Application is handled on local machines only.
- No QuickBooks Online data is transmitted to third-party servers or stored in cloud environments.
- OAuth tokens are stored locally with restricted file system access.
- Temporary data files (JSON caches, token files) are created during migration runs and can be deleted after completion.
